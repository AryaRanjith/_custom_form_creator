Custom Form Builder

Overview
The Custom Form Builder is a web application developed using React, Node that allows users to create, manage, and share dynamic forms. The application is designed to replicate core functionalities of modern form tools (such as Google Forms), while maintaining a clean architecture and responsive user experience. It supports dynamic question creation, real-time preview, response collection, and data export.

Features 2.1 Form Builder (Editor Mode) Dynamic creation of form fields, Multiple question types: Text input (short and long answer) Multiple choice, Checkboxes, Dropdown, Duplicate existing questions, Mark fields as required
2.2 Preview Mode Live preview of the form before sharing, Validation for required fields, Responsive design for mobile and desktop, Submission confirmation screen,

2.3 Response Management Store and display submitted responses, Tabular view of collected data, Export responses in CSV format, Option to delete individual or all responses,

2.4 Sharing Generate and share a form link, Easy access for end users to submit responses,

Technology Stack Nodejs, Reactjs, JSON file
